# Product Brief

## Product
Numind is an iOS-first learning app that helps users build practical number sense through short daily lessons and quizzes. Calculators are deferred to the future website and are not part of the iOS app.

## Core Promise
Train quick math for real life.

## Target User
Adults and young adults who want to become faster and more confident with everyday math without feeling like they are using a school tutoring app.

## V1 Wedge
Practical number sense:
- tips
- bill splits
- discounts
- percentages
- sales tax
- mental math shortcuts

## Long-Term Monetization
Long onboarding → diagnostic test → preliminary evaluation → personalized plan → hard paywall with 7-day free trial.

## Immediate Build Priority
Core product loop first:
Home → Module → Lesson → Quiz → Feedback → Progress.

## Non-Goals For First Build
- no real payments
- no real backend
- no AI generation
- no social features
- no content CMS
- no Android
