# Product Brief

> **Last updated:** May 2026 (after M56).

## Product
Numind is an iOS-first learning app that helps users build practical number sense through short daily lessons and quizzes. Calculators are deferred to the future website and are not part of the iOS app.

## Core Promise
Get faster at everyday money math in 5 minutes a day.

## Target User
Adults and young adults (roughly 22-40) who want to become faster and more confident with everyday math without feeling like they are using a school tutoring app.

They may feel slow or rusty with splitting bills, calculating tips, judging discounts, estimating totals, interpreting percentages, understanding loan costs, or comparing salary offers.

## V1 Wedge
Practical number sense across 8 topic areas:
- **Tips** - tip calculation, pre/post-tax, bill splitting
- **Discounts** - percentage off, BOGO, stacked discounts, unit pricing
- **Money Math** - budgeting, subscriptions, cost per use, sales tax, cart estimation
- **Salary** - net pay, raises, overtime, pay period conversion
- **Investing** - simple interest, Rule of 72, ROI
- **Estimation** - rounding, hourly rate, percent change, doubling/halving, multiply by 5
- **Debt** - credit card interest, minimum payments, loans, DTI, extra payments
- **Travel** - currency conversion, exchange fees, travel budgets, accommodation, insurance

**Total: 8 modules, 37 lessons, 187 quiz templates**

## Core Loop
Home -> pick a lesson from the zigzag learning path -> read short lesson (concept + shortcut + example) -> quiz (8 template-generated questions) -> instant feedback per question -> session summary with XP, mastery, personal best, badges -> progress update (streak, levels)

## Long-Term Monetization
Long onboarding -> diagnostic test -> preliminary evaluation -> personalized plan -> hard paywall with 7-day free trial.

## Immediate Build Priority
Core product loop first:
Home -> Learn (zigzag path) -> Lesson -> Quiz -> Feedback -> Summary -> Progress.

## Non-Goals For First Build
- no real payments
- no real backend
- no AI generation
- no social features
- no content CMS
- no Android
- no calculator tools (deferred to website)
- no push notifications (local reminders only)
