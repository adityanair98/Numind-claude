# Numind

Numind is an iOS-first learning app for building practical number sense through short daily lessons and quizzes.

## Core Product
A friendly daily trainer for tips, bill splits, discounts, percentages, and practical mental math. Calculators are a future website feature, not part of the iOS app.

## Current Build Stage
Stage 0: repo setup and product foundation.

## Stack
- iOS: SwiftUI
- Backend later: Supabase
- Payments later: RevenueCat + Apple IAP
- Analytics later: PostHog
- Website later: Next.js on Vercel

## First Milestone
Build the core app loop locally:
Home → Module → Lesson → Quiz → Feedback → Progress.
