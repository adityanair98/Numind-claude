# AGENTS.md

This repository contains Numind, an iOS-first SwiftUI app for practical number sense.

## Core Rule
Build the core product loop first:
Home → Module → Lesson → Quiz → Feedback → Progress.

## Do Not Build Yet
- backend
- real payments
- AI generation
- social features
- admin CMS
- Android

## Brand
Friendly, clean, App Store-first, blue/teal/yellow, bead/rail motif.

## Implementation
Use SwiftUI, MVVM, local-first content, and centralized design tokens.
